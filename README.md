# 📞 Call Center Performance Dashboard

## 📌 Project Overview

This project showcases an **interactive Call Center Dashboard** designed using **Power BI**. The dashboard provides a clear view of **call center operations**, including total calls, response efficiency, agent performance, and customer satisfaction. It enables management to monitor KPIs, optimize resources, and improve overall service quality.

---

## 🔑 Key Features

* **Total Calls Overview**

  * Total Calls: **5,000**
  * Answered Calls: **4,054**
  * Rejected Calls: **946**

* **Call Efficiency Metrics**

  * Average Speed of Answer: **67.52 seconds**
  * Average Call Duration: **225 seconds**

* **Customer Satisfaction**

  * Overall Satisfaction Rating: **3.40 / 5**
  * Satisfaction tracked per agent

* **Performance by Agent**

  * Calls answered, rejected, resolved, and unresolved per agent
  * Average call duration, speed of answer, and satisfaction rating for each agent

* **Trends & Insights**

  * Answered vs Unanswered Calls by Month (Jan, Feb, Mar)
  * Topics handled (Admin Support, Contract, Payments, Streaming, Technical Support)
  * Satisfaction ratings over time

---

## 📂 Tools & Technologies

* **Microsoft Power BI** (Data Modeling, DAX, Interactive Visuals)
* **Excel data sources** for call logs and customer feedback
* **KPIs & slicers** for months, resolution status, and topics

---

## 🚀 How to Use

1. Open the Power BI dashboard file (`.pbix`).
2. Use the filters to drill down by **Month, Topic, or Resolution Status**.
3. Explore **agent-level insights** to monitor performance.
4. Track **monthly answered vs unanswered calls**.
5. Monitor **satisfaction rating trends** to identify improvement areas.

---

## 📈 Business Value

This dashboard helps organizations:

* Monitor **agent efficiency and workload distribution**
* Identify **bottlenecks in call response and resolution**
* Track **customer satisfaction across topics and agents**
* Enhance **decision-making with actionable insights**
